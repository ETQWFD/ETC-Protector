# 杀毒软件误报说明与处理方案（ETC+ 加固卫士）

## 为什么加固工具容易被报毒

安全软件对「会读写/重打包 APK、处理 ZIP、含文件校验逻辑」的工具普遍使用启发式规则，
未签名的原生可执行程序容易被归类为「打包器 / 修改工具」风险类别。这是**误报**，
与本工具的用途（防篡改加固自身 APK）无关。本项目从不包含：木马、挖矿、盗号、广告注入等恶意行为。

## 本项目已做的降低误报设计

| 设计 | 说明 |
|---|---|
| 原生 C++ 静态编译 | 桌面版为纯 Win32 原生程序，非 PyInstaller 脚本打包，无 Python 解释器特征 |
| 静态链接 | 不依赖第三方运行库 DLL，行为特征简单 |
| 小体积 | 3 MB 单文件，无释放型载荷、无联网行为 |
| 明确品牌标识 | 版本信息、图标、数字签名说明齐全 |

## 如果 360 / 其他杀软仍提示风险

1. **加白名单**：在 360 安全卫士「信任区 / 恢复区」添加 `ETC_Protector.exe` 或解压目录；
2. **误报申诉**：打开 360 安全卫士 → 查杀恢复区 → 找到误报文件 → 「误报反馈/申诉」上传样本，
   说明为 APK 加固工具，官方核实后 1~3 个工作日解除；
3. **官方渠道下载**：仅从本项目 GitHub Release 下载，避免第三方修改版被植入风险；
4. **正式签名（推荐长期方案）**：购买 OV/EV 代码签名证书（如 DigiCert、GlobalSign、中国 CA 机构），
   用 `signtool sign` 对 EXE 签名后，主流杀软信任度大幅提升；
5. **系统自带防护**：Windows Defender 若提示，选择「仍要运行」，并把文件加入排除项。

## 声明

- 本工具为合法软件，用于开发者/用户对自有 APK 进行防篡改加固；
- 禁止用于破解、盗版、篡改他人应用等非法用途；
- 杀毒软件误报不影响工具功能，按上述方案处理后即可正常使用。

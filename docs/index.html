加固原理

不碰 DEX——不注入壳、不改字节码，应用安装后正常使用、不闪退；

全文件 SHA-256 清单——加固时计算 APK 内所有文件哈希并加密写入清单，任何篡改都会被检测；

品牌标识注入——MT 管理器与系统「加固状态」字段显示 ETC+加固；

禁止二次加固——已加固 APK 导入即被识别并拒绝；

输出全新文件——自动 zipalign + v2/v3 签名，可直接安装。

常见问题

选 APK 提示「不是有效类型」？

已修复：三端改为「含 AndroidManifest.xml 即有效」，不再强制要求 DEX，兼容各类现代 APK 结构；文件选择器不再限制 MIME。

Windows 左上角图标不显示？

已修复：修正图标资源 ID 匹配并强制注入窗口大小图标，标题栏与任务栏均显示 ETC+ 盾牌图标。

加固后标签显示什么？

加固后「加固状态」字段与 MT 管理器显示 ETC+加固，已加固 APK 禁止二次导入。
